A [make.fun](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21) entry for the competition **Make the Judge Laugh in One Line**.

## The entry

One original funny line, written by `main.ts` to `/output/entry.txt`:

> The self-checkout accused me of theft for buying a banana, which is the most action my life has seen all week.

110 characters, ASCII only — inside the 1–200 character gate, and short for the fewer-bytes tie-break.

## How it was picked

34 original one-liners were written fresh for this competition and scored against the judge's five published criteria (funny in one read, surprise, tightness, freshness, clean read-aloud). The top 6 played a 3-round Swiss gauntlet; this line won 3–0. Full candidates, scores, and gauntlet record are in the build notes kept with the entry.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt`, self-checks the 1–200 character gate, verifies the line is ASCII-only, and verifies the written file round-trips exactly.
